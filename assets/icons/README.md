# Bundled platform marks

The PNG assets are small, transparent 48×48 brand marks used by the dashboard and packaged into AIHub.exe. Most are Simple Icons vectors rendered to PNG at build-authoring time; the Simple Icons project is CC0 1.0 Universal: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Included source marks: OpenAI (Simple Icons v13.11.0), Google Gemini, Claude, DeepSeek, Perplexity, X, Poe, Meta AI, Hugging Face (used to represent HuggingChat), and Mistral AI (Simple Icons v16.36.0). Microsoft Copilot uses Microsoft's four-color window mark; Arena.ai uses a custom letterform because a verified brand mark was not present in the source icon library. All marks are local; the app does not fetch logos at runtime.
